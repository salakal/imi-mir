# IMI: публикация существующего проекта

Production: https://imi-mir.vercel.app. Project: `imi-mir`, scope: `vadimkamatveev07-2378`.

В архиве исходники для существующего проекта. Извлеките папку `college-mir`; не создавайте новый проект Vercel. Команда Vercel для сборки задана в `vercel.json`: `next build`. Требуется Node.js 22.13 или новее.

## Предпочтительный постоянный путь: Git

1. Создайте приватный GitHub-репозиторий `imi-mir` в своей учётной записи и загрузите в корень репозитория содержимое папки `college-mir`. Не загружайте `.env*`, `node_modules`, `.next`, `.vercel`, токены и ключи. Эти файлы исключены из архива; `.gitignore` дополнительно исключает их из Git.
2. В Vercel откройте **imi-mir → Settings → Git → Connected Git Repository → GitHub**. Если Vercel предложит установить GitHub App, выберите свою учётную запись и дайте доступ только репозиторию `imi-mir`. Затем найдите `imi-mir` и подключите его к **существующему** проекту.
3. Убедитесь, что **Root Directory** указан как корень репозитория, **Framework Preset** — Next.js, production branch — `main`, а `imi-mir.vercel.app` остаётся доменом проекта. Сверьте значения переменных окружения с прежними настройками проекта, ничего не очищайте.
4. Опубликуйте сначала изменение в отдельной ветке или PR для preview. Проверьте группы, расписание, долги, поиск преподавателей, кабинеты, сессии, мобильную ширину. После успешной проверки объедините ветку с `main` и откройте `https://imi-mir.vercel.app` для проверки production.

До настройки Git не публикуйте архив через форму создания нового Vercel-проекта. В этой среде облачный Vercel connector не имеет прав на scope проекта, а терминал не соединяется с Vercel API. Готовность архива и успешная локальная сборка **не означают**, что production уже обновлён.

## Локальная проверка

```
corepack pnpm install --frozen-lockfile
./node_modules/.bin/next build
node --experimental-strip-types --test tests/pdf-parsers.test.mjs
```

Проверка 47 групп по официальным PDF описана в `scripts/check-sessions.mjs`; файлы передаются аргументами и не включаются в репозиторий. Доступ к актуальным официальным документам приложение получает через существующий источник Яндекс.Диска.
