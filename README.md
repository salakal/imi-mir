# IMI

Студенческий сервис колледжа «МИР» и факультета СПО: расписание, задолженности, дисциплины сессии и поиск преподавателей. Production: https://imi-mir.vercel.app. Старый адрес `mir-kisp-49-1.vercel.app` оставлен для совместимости.

## Источники

Сведения загружаются из [публичной папки учреждения](https://disk.yandex.ru/d/KTpb1wS1l0-amA). Серверные маршруты `app/api/catalog`, `manifest`, `schedule-sources`, `session-sources` находят опубликованные файлы; `app/api/pdf` проверяет их путь и передаёт PDF браузеру. `lib/pdf-data.ts` читает расписание и жёлтые клетки ведомостей, `lib/sessions.ts` читает опубликованные дисциплины зачётов и экзаменов. Файлы сессии 2026–2027 пока не содержат дат, кабинетов и времени.

Поиск преподавателей строится из тех же PDF расписания: общий файл загружается один раз на выбранную неделю, его группы разбираются вместе, затем пары объединяются по преподавателю в `lib/teachers.ts`. Повторный поиск по буквам не скачивает PDF; кнопка «Обновить» запрашивает файлы заново.

Выбранная группа и личные отметки долгов хранятся в `localStorage` устройства. Они не меняют официальную ведомость.

## Разработка

Требуются Node.js >= 22.13 и pnpm 11.25. Запуск: `pnpm install`, затем `pnpm dev`. Проверка сборки Vercel: `npx next build`. Публикация в существующий проект `imi-mir`: `vercel deploy --prod --yes` из корня проекта после привязки через `vercel link`.

В `public/brand` лежат логотип, иконки, social preview и QR на production URL. При смене production адреса одновременно обновить `app/layout.tsx`, `app/page.tsx` и оба QR asset.
